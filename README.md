## 👋 About

I build quantitative trading infrastructure and the LLM systems that read the documents around it — pricing libraries and market data services in C++, structured extraction and evaluation pipelines in Python and TypeScript.

- 🔭 Recent work: derivatives pricing and trade capture, verified assertion graphs from source text, typed LLM evaluation with Jev and the AI SDK
- 🧰 Tooling: Claude Code skills, agents, and MCP servers, versioned across machines from a dotfiles repo
- 💬 Ask me about C++ pricing engines, or getting structured output out of language models reliably
